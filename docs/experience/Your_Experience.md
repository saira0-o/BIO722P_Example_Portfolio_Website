# Genome Assembly using SPAdes

## Content
Provided datasets of 5 bacterial contaminated human samples.
Datasets contained paired Illumina and Nanopore reads.
Samples A,B,D,E datasets contained Illumina and corresponding Nanopore
Sample C's dataset contained only paired Illumina reads. 

Assemblies were generated using SPAdes and SPAdes hybrid.
